# Security Reporting

To report a security vulnerability in this project privately, use GitHub's
private vulnerability reporting:

<https://github.com/diggsweden/DCAT-AP-SE-Processor/security/advisories/new>

You may also email ospo AT digg.se

When reporting, please include:

- PUBLIC: Whether the vulnerability has already been made public or discussed
  publicly, and if so, where.
- DESCRIPTION: A precise description of the vulnerability, with as much detail
  as you are able and willing to provide.

Vulnerabilities reported will be handled on a best effort basis. We will let
you know within a few weeks whether the report has been accepted or rejected.
We ask that you keep the report confidential until a public announcement has
been made.
